# MindMap AI — локальная база знаний с системой тегов

**Курсовой проект** — WPF-приложение для создания персональной базы знаний с тегированием заметок.

---

##  Состав решения

| Проект | Назначение |
|--------|------------|
| **MindMapAI** | WPF-клиент с MVVM-архитектурой, современный UI |
| **MindMapAICore** | Бизнес-логика: модели данных, сервис базы данных |
| **MindMapAI.Tests** | xUnit-тесты (DatabaseService + ViewModel) |

---

##  Технологии

| Технология | Назначение |
|------------|------------|
| **C# / .NET 10.0** | Основной язык и платформа |
| **WPF** | Современный UI с поддержкой MVVM |
| **SQLite** | Локальное хранение данных (файл `notes.db`) |
| **CommunityToolkit.Mvvm** | Реализация паттерна MVVM (RelayCommand, ObservableProperty) |
| **xUnit + Moq** | Модульное тестирование |

---

##  Возможности

### Заметки (CRUD)
-  Создание заметки (заголовок + содержание)
-  Редактирование с автосохранением
-  Удаление с подтверждением
-  Список всех заметок, сортировка по дате изменения

### Теги
-  Добавление тегов к заметке
-  Редактирование и удаление тегов
-  Отображение тегов над заголовком (кликабельные плитки)
-  Поиск по заголовку и тегам

### Интерфейс
-  Тёмная тема (дизайн в стиле Obsidian)
-  Адаптивная двухколоночная компоновка
-  Доступность для скринридеров (NVDA, экранный диктор Windows)
-  Настройки (размер шрифта, статус автосохранения)

### Прочее
-  Локальное сохранение в SQLite
-  Автосохранение при переключении заметок
-  Заглушки для будущих функций (ИИ-анализ, граф связей, папки)

Покрытие тестами:

Структура проекта

MindMapAI/
├── MindMapAI/                        # WPF приложение (View)
│   ├── Assets/                       # Иконки и изображения
│   ├── ViewModels/                   # ViewModel слой
│   │   ├── MainViewModel.cs
│   │   ├── ViewModelBase.cs
│   │   └── Converters/
│   └── MainWindow.xaml

│   ├── Services/                     # DatabaseService (SQLite)
│   └── Interfaces/                   # IDatabaseService

└── README.md

Запуск

1. Открыть MindMapAIApp.slnx в Visual Studio 
2. Выбрать конфигурацию Debug или Release
3. Нажать F5

При первом запуске: база данных SQLite автоматически создаётся в %LocalAppData%/MindMapAI/notes.db
